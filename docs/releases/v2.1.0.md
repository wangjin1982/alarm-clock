# 桌面闹钟 v2.1.0

## 本次更新

- 新增倒计时功能：可以设定一个下课/会议时间点到点倒数，也可以直接选 15/30/45/60 分钟快捷时长；支持暂停、继续、延长 5 分钟和取消。
- 倒计时状态本地持久化，重启应用不丢失；到点后通过语音播报和系统通知提醒，应用不在前台也能触发。
- 新增天气卡片：自动定位当前位置并显示实时天气（温度、天气现象、湿度、风速），每 30 分钟自动刷新，可一键语音播报。
- 定位采用三级降级策略：macOS 系统定位 → IP 定位 → 手动城市；手动指定的城市会持久保存，点定位按钮可随时恢复自动定位。
- 修复历史问题：城市名中的空格被误删导致英文城市（如 San Francisco）查询失败；原 IP 定位服务失效，已替换为更稳定的 ipwho.is。
- 主界面改为风琴式折叠布局：番茄钟、倒计时、天气、闹钟四张卡片默认收起，标题栏显示实时摘要，展开状态会自动记住。
- 为倒计时工具函数引入 vitest 单元测试（16 个用例）。

## 修复说明

- macOS 打包信息中补充了定位权限声明（NSLocationWhenInUseUsageDescription），正式包首次使用定位时会弹出系统授权弹窗。
- 开发模式（tauri dev）下系统定位不可用属于 macOS 对未打包应用的限制，会自动降级为 IP 定位或手动城市。

## 升级说明

- 不涉及破坏性改动，已有闹钟、番茄钟和设置会继续沿用。
- 天气数据来自 Open-Meteo 免费接口，无需配置 API Key。
- 使用代理（如 Clash）时 IP 定位可能显示代理出口城市，建议在系统授权弹窗中允许定位，或手动输入所在城市。
