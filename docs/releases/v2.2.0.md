# 桌面闹钟 v2.2.0

## 本次更新

- **新增数字时钟**：固定展示在主界面顶部（时:分:秒 + 日期星期），识别到城市天气后在日期下方同步显示"天气图标 + 温度 + 城市"。
- **新增 5 款皮肤**：深空（默认）/ 森林 / 深海 / 暮色 / 晨雾（浅色），设置中一键切换，即时生效并记住选择。
- **修复倒计时到点重复提醒**：此前桌面版会先响系统语音再响一遍电子音色，现在只播报一次。
- **天气定位策略优化**：
  - IP 定位结果仅在中国境内时采用，代理（VPN/Clash）导致的境外城市不再显示；
  - 定位不可用时默认显示**镇江**天气（内置坐标，必定出结果）；
  - 浏览器环境定位授权挂起时 12 秒自动降级，不再卡在"定位中"。

## Windows 版说明

- 下载 `alarm-clock_2.2.0_windows_portable.zip`，解压后直接运行 `桌面闹钟.exe`，无需安装。
- 首次运行如提示缺少 WebView2，请安装 Microsoft Edge WebView2 Runtime（Win10/11 通常已内置）。
- 天气功能需要联网；使用代理时天气默认显示镇江，可在天气卡片手动输入所在城市。

## 升级说明

- 从 v2.1.x 升级无破坏性改动，倒计时、闹钟、设置自动沿用。
